Python Tutorial: Building a Student Information Form

Last Updated: Today | Read Time: 6 mins

1. Introduction

Learning how to receive input from a user and present it cleanly is a cornerstone of programming. In this tutorial, we break down a Python script designed to act as a Student Registration Portal. By the end of this guide, you will understand how basic printing, input capturing, and string formatting combine to build a complete interactive console program.

2. Full Program Code

Here is the full script we will be analyzing step-by-step:

student_form.py Python 3 
# Student Information Form Tutorial
print("WELCOME TO THE STUDENT REGISTRATION PORTAL")

# Collecting user input
student_name = input("Enter your full name: ")
student_age = input("Enter your age: ")
grade_level = input("Enter your grade or year level: ")
school_name = input("Enter your school name: ")
course_track = input("Enter your track or major: ")

# Displaying the collected information
print("\n" + "="*40)
print("  STUDENT PROFILE SUCCESSFULLY CREATED")
print("="+40)
print(f"Name:         {student_name}")
print(f"Age:          {student_age}")
print(f"Grade/Level:  {grade_level}")
print(f"School:       {school_name}")
print(f"Track/Major:  {course_track}")
print("="+40)

3. Step-by-Step Tutorial Breakdown

Step 1

Displaying Banners with the print() Function

The print() function outputs text to the screen. At the start of our program, we use it to greet users and display a clear header for our registration portal:

print("WELCOME TO THE STUDENT REGISTRATION PORTAL")

This sets a clean interface standard for anyone executing the script.

Step 2

Capturing Runtime Data with the input() Function

To collect personal details, we assign variables to the result of the input() method. Python pauses execution, prints your prompt string, and waits for keyboard entry:

student_name = input("Enter your full name: ")

Whatever the user types is safely stored inside the student_name variable as a string.

Step 3

Formatting Output using f-strings and Operators

Once variables are collected, we use string multiplication ('='*40) to draw borders, and f-strings (prefixed with f) to inject variable values dynamically:

print(f"Name: {student_name}")

The curly braces {student_name} get evaluated and replaced with the user's actual typed input upon printing.
